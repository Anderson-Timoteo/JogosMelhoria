# Exercício dos Números · 5S

Jogo do treinamento de 5S do **PEL · Programa de Excelência Logística** (Assaí · Supply / CDs).

Encontre os números de **1 a 49, em ordem**, em 1 minuto. São 6 rodadas: sem 5S e depois um senso por vez. A cada rodada o quadro fica mais organizado e, no fim, você compara as suas pontuações.

> "O mesmo trabalho, as mesmas pessoas: só o ambiente mudou."

## Como acessar

- **Participantes:** abram o link no celular → https://anderson-timoteo.github.io/JogosMelhoria/
- **Facilitador (telão):** https://anderson-timoteo.github.io/JogosMelhoria/?modo=apresentador
  - `→` avança · `←` volta · `F` tela cheia
  - Nas telas de senso há uma barra de 20 s (pausar / pular), seguida da contagem de 10 s.

Não precisa instalar nada nem criar conta. As pontuações ficam só no celular de cada pessoa (`localStorage`).

## Como funciona

- Tudo está em um único `index.html` (HTML + CSS + JS), sem build.
- Todos veem o **mesmo quadro** (semente 7, igual ao material master).
- Ao recarregar a página, o jogo continua de onde parou. "Jogar de novo" apaga tudo.

## Publicação

GitHub Pages, branch `main`, pasta raiz. Qualquer push na `main` atualiza o site em 1 a 2 minutos.
